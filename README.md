# Física 2D — Sandbox

Um sandbox de física 2D interativo feito com HTML, CSS e JavaScript puro, usando [Matter.js](https://brm.io/matter-js/) como motor de física.

🔗 **Acesse aqui:** https://2d-sandbox-physics.vercel.app/

## Como usar

- Clique para soltar objetos na tela
- Pressione `H` para abrir a ajuda com todos os atalhos
- `Espaço` pausa/retoma a simulação

## Tecnologias

- HTML5 / CSS3
- JavaScript (vanilla)
- [Matter.js](https://brm.io/matter-js/) para a simulação física
